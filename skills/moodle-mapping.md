# Skill: moodle-mapping

Einsatz bei: Uebersetzung von Kursartefakten in Moodle-Struktur

## Ablauf

1. Lade Module Blueprint, Content Bundle, Assessment Bundle, Gamification Spec
2. Weise jedem Lernschritt einen Moodle-Typ zu:
   - Einstieg → Label / Textseite
   - Fachinhalt → Seite / Buch
   - Interaktion → H5P / Lektion
   - Aufgabe → Assignment
   - Quiz → Test
   - Reflexion → Forum / Feedback
3. Definiere Completion-Tracking-Regeln pro Aktivitaet
4. Dokumentiere Restrict-Access-Logik
5. Lege Badge-Ausloeser fest
6. Schreibe Pflegehinweise fuer Lehrkraefte

## Ausgabe
Moodle Mapping Sheet:
- Abschnitt
- Aktivitaetstyp
- Titel
- Completion-Regel
- Restrict Access
- Badge-Ausloeser
- Pflegehinweise

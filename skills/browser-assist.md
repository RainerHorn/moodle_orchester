# Skill: browser-assist

Einsatz bei: Manueller Uebertragung in gehostetes Moodle ohne Serverzugriff

## Ablauf

1. Lade Moodle Mapping Sheet
2. Pruefe alle Schritte auf benoetigte Rechte (kein Admin voraussetzen)
3. Erstelle klickgenaue Schritt-fuer-Schritt-Anleitung:
   - Kursabschnitt anlegen
   - Aktivitaet hinzufuegen (Typ, Titel, Einstellungen)
   - Completion-Regel setzen
   - Restrict Access konfigurieren
   - Badge anlegen und Ausloeser setzen
4. Markiere optionale Schritte, die Adminrechte benoetigen
5. Liefere Fallback-Loesungen fuer nicht verfuegbare Features

## Ausgabe
Browser-Assist-Anleitung:
- Geordnete Schritt-fuer-Schritt-Liste
- Screenshots-Hinweise (Bereich in Moodle UI)
- Rechtebedarf je Schritt
- Fallback-Optionen
